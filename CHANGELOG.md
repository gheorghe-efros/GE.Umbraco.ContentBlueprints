# Changelog

All notable changes to this package are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the package follows
[Semantic Versioning](https://semver.org/).

## [1.0.0] - Unreleased

### Added

- Document Blueprints menu in the Content section, shown to users who have access
  to Content and the new **Document Blueprints → Access in Content** user group
  permission.
- Management API access to the Document Blueprint endpoints for those users. Users
  with access to Settings keep exactly the access Umbraco gives them.
- Supports Umbraco 17 and 18.
